# Oramusa

Starter website for Oramusa.com.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deploy to Vercel

1. Push this folder to a new GitHub repository.
2. Import the repository into Vercel.
3. Add `oramusa.com` under Project → Settings → Domains.
4. Follow Vercel's DNS instructions in GoDaddy.
